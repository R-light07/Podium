- Layout novo: **Logo + Pesquisa à esquerda** · Links ao centro · Acções (favoritos, menu) à direita
- **Dropdowns expansíveis** em hover/click: "Desportos" (com lista de 6 desportos) e "Mais" (Agenda, Podcasts, Classificações, Favoritos, Sobre Nós)
- **Pesquisa live** com resultados em dropdown, highlight da query, mín. 180ms debounce
- **Versão mobile**: pesquisa colapsa para ícone; menu hamburger opaco fullscreen com dropdowns inline
- Links: Início, Desportos, Resultados, Assistir, Mais (Agenda ficou no "Mais")
- Ícones em **SVG inline** (não dependem de FontAwesome — continuam a funcionar mesmo se o CDN falhar)

### Hero slider
- Carrossel com 3 destaques (notícias marcadas `destaque: true`)
- **Autoplay 3s** com barra de progresso visível
- Setas anterior/próximo (teclado ← → também funcionam)
- Dots de navegação com pill activo
- **Swipe em mobile** (touch events)
- Pausa no hover; pausa quando tab perde foco
- Animações de entrada escalonadas (eyebrow → meta → título → descrição → CTA)
- Respeita `prefers-reduced-motion`

### Notícias
- Renderização **100% dinâmica** a partir de array em `script.js` (12 notícias mock)
- **Filtros por categoria** (chips): Todas, Futebol, Basketball, Ténis, Atletismo, Motorsport, Voleibol
- **Paginação "Carregar mais"** (6 cards por página)
- **Favoritos** guardados no localStorage — badge no header mostra contador
- **Botão de favorito em cada card** (coração que enche quando activo)
- **Skeleton loading** enquanto carrega

### Modal de notícia individual
- Abre ao clicar em qualquer card ou resultado de pesquisa
- Mostra: categoria, data longa, autor, título, lead, conteúdo completo
- **Acções de partilha**: Facebook, X/Twitter, WhatsApp, copiar link
- Botão de favorito também dentro do modal
- Fecha com ESC, clique no X, ou clique no backdrop

### Acessibilidade
- Skip link para conteúdo
- `aria-label`, `aria-expanded`, `aria-selected`, `role` em todos os controles interactivos
- `aria-live="polite"` nas regiões dinâmicas (resultados de pesquisa, notícias, mensagens de form)
- `prefers-reduced-motion` respeitado (anula animações pesadas do slider)
- Contraste adequado em toda a UI

### SEO / Performance
- Meta descrição, Open Graph tags, lang="pt", theme-color
- Preconnect a Google Fonts
- Lazy loading implicito nos emojis (sem imagens a bloquear render)
- Sem CLS — navbar fixa sem saltos

## Migração para Supabase (próximos passos)

O código está estruturado para migração trivial. Tudo passa pelo objecto `api` em `script.js`:

### Setup Supabase
```html
<!-- Adicionar antes do </body> -->
<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2/dist/umd/supabase.min.js"></script>
```

### Tabelas sugeridas
```sql
-- categorias
create table categorias (
  id bigint primary key generated by default as identity,
  slug text unique not null,      -- 'futebol', 'basketball', etc
  nome text not null,
  emoji text,
  ordem int default 0
);

-- noticias
create table noticias (
  id bigint primary key generated by default as identity,
  titulo text not null,
  resumo text not null,
  conteudo jsonb,                 -- array de parágrafos
  imagem_url text,
  categoria_id bigint references categorias(id),
  autor text,
  destaque boolean default false,
  data_publicacao timestamptz default now()
);

-- RLS: permitir leitura pública
alter table noticias enable row level security;
create policy "public read" on noticias for select using (true);

alter table categorias enable row level security;
create policy "public read" on categorias for select using (true);
```

### Substituir o objecto `api` em script.js
```js
// Em vez de:
//   const NEWS_DATA = [...]
// Usar:
const SUPABASE_URL  = 'https://<project>.supabase.co';
const SUPABASE_KEY  = '<anon_public_key>';  // OK em cliente; RLS protege
const sb = supabase.createClient(SUPABASE_URL, SUPABASE_KEY);

const api = {
  async fetchNews(filter = 'all') {
    let q = sb.from('noticias')
      .select('*, categorias(slug, nome, emoji)')
      .order('data_publicacao', { ascending: false });
    if (filter !== 'all') q = q.eq('categorias.slug', filter);
    const { data } = await q;
    return data || [];
  },
  async fetchHeroSlides() {
    const { data } = await sb.from('noticias')
      .select('*, categorias(slug, nome, emoji)')
      .eq('destaque', true)
      .order('data_publicacao', { ascending: false })
      .limit(5);
    return data || [];
  },
  async searchNews(query) {
    const { data } = await sb.from('noticias')
      .select('*, categorias(slug, nome, emoji)')
      .textSearch('titulo', query, { config: 'portuguese' })
      .limit(6);
    return data || [];
  }
};
```

### Segurança
- **Anon key é segura no cliente** — é pública por design, desde que as políticas RLS estejam activas
- Para operações de escrita (dashboard admin), use auth do Supabase e políticas RLS baseadas em `auth.uid()`
- Nunca coloque a `service_role` key no frontend
